## Today vs. after phase 5

Today the venue PCs **build Bluvu themselves**: they clone the repository, and the installers download
the NDI SDK from ndi.tv, where the venue accepts NDI's license. We hand out source code, not binaries.

Phase 5 (release bundles) changes that: we'll ship a built `mosaic_engine.exe` with the NDI DLL and the
built editor next to it. From then on we're *distributing* every component above, so:

- `THIRD_PARTY_NOTICES.txt` goes in every bundle (it's generated by `mosaic-engine/tools/make_notices.py`;
  CI should run it with `--check`).
- The NDI DLL ships in Bluvu's own folder, never in the system path (NDI asks for this).

## NDI: what its published terms ask

From NDI's licensing page (docs.ndi.video, "Licensing") and the SDK pages on ndi.video, read on
2026-11-26:

1. **A link to `https://ndi.video/`** near every place in the product where NDI is used or selected, on
   our website, and in our documentation.
   - Done: the editor's NDI source picker ("About NDI®"), Settings → About, and the site footers.
   - To do: the user docs (phase 7).
2. **Trademark line**, "NDI® is a registered trademark of Vizrt NDI AB", near the first use of NDI on a
   page or in a footnote, and in the About box.
   - Done: Settings → About, the site footers, `LICENSE`, the EULA and the notices.
3. **Ship the DLL with the application**, in its own folder, not the system path. The NDI Tools
   themselves must not be redistributed (link to `https://ndi.video/tools/` instead).
   - `setup-receiver.ps1` downloads the Tools from NDI, which is fine.
4. **"NDI" in a product name** needs NDI's permission. "Bluvu" is fine. Output names like
   "Camera (NDI)" describe a stream, not a product.
5. **Commercial use:** the SDK is royalty-free "subject to the SDK terms and conditions". The download
   page says NDI's business team may get in touch depending on expected revenue (no threshold given).
   NDI also asks makers of commercial products to let them know.
   - Recommended: tell NDI about Bluvu before launch (https://ndi.video/resources/get-in-touch/).
6. **Codecs:** if Bluvu ever sends or receives NDI|HX (H.264/H.265) or AAC, licensing those codecs is
   our job. Today Bluvu uses full-bandwidth NDI (UYVY/BGRA), so this doesn't apply yet.

**Not checked yet, and the most important:** the full *NDI SDK License Agreement* isn't on NDI's
website. It comes in the root folder of the SDK install (on the media server:
`C:\Program Files\NDI\NDI 6 SDK\`), along with a "3rd party rights" section in the SDK manual. It's
likely to require terms in *our* EULA on NDI's behalf (typically: no reverse engineering of the NDI
libraries, and NDI disclaiming warranties and liability). EULA section 8 has a placeholder for them.

- **Next step:** copy that file off MEDIA-SERVER (or install the SDK on any PC), and fill in EULA 8.2
  from it.

## Other things to check

- **Pictures and video on the website** (`site/media/`): make sure Blue Arc Networks owns them or has
  permission. Most look like the venue's own walls; get the venue's OK to show them, and their logo if
  it's visible.
- **The Windows build:** `mosaic_engine.exe` built with MSVC needs the Visual C++ runtime, which
  Microsoft allows us to redistribute (its "redist" licence). Ship `vc_redist.x64.exe`, or build with a
  static runtime (`/MT`), in phase 5.
